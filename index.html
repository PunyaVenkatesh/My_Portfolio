Crisis Response AI

Multi-agent emergency response with validated hand-offs

Field report → Situation → Resources → Planner → Comms
  • Four agents turn a raw field report into a severity assessment, resource allocation, time-phased action plan and public messaging.
  • Agents pass each other Pydantic-validated objects, not prose — a plan with no 0–1h action or an out-of-range severity is rejected outright.
  • On validation failure the model is handed its own output plus the exact error and asked to correct itself once, then fails loudly rather than returning a plausible-looking plan.
